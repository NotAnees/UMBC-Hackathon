## Design Specificity Verdict

LLM assessment: category-interchangeable shell with three authored details. 220px sidebar, uniform .panel cards, pill badges, two tables — swap "phishing" for "invoices" and nothing structural resists. Authored: SpanHighlighter marking quoted phrases in the body; RiskComponents contribution bars; the "scored on 60% of signals" honesty line.

The incumbent it copied its palette from (backend/app/static/index.html) renders the verdict as a tinted banner with a 40px colored score. This renders 34px neutral with a small pill. The one question the product answers has the visual weight of a KPI tile, and the thing it replaces did it better.

Deterministic scan: 0 findings, exit 0 — a FALSE NEGATIVE, not a pass. The bundled detector only parses HTML. Proven with a control: a .tsx/.css fixture with gradient text, 11px gray copy, fake-depth shadow and a marketing buzzword returned []; the identical .html returned 8 findings, exit 2. Deterministic coverage is unavailable for this target.

Hand-computed instead: all 14 declared contrast pairs pass AA (worst badge.red 5.91:1; --muted 6.82:1; body 16.54:1). No type below the 11px floor (smallest exactly 11.0px). Clean on gradient-text, codex-grid-background, marketing-buzzword. Only gradient is styles.css:397, cyan→cyan on a bar. Advisory: 14 em-dashes across 6 TSX files. The two teammate dashboards DO fail undersized-ui-text at 10px; this app does not.

Where the review beat the scan: token-pair math said all pairs pass, but tr.off { color: var(--muted); opacity: .6 } composites to ~3.46:1 at 12.5px — a real AA failure that declared-pair analysis structurally misses.

Visual overlays: none. No browser automation exposed; live-server injection skipped. No overlay exists; no rendered-DOM scan was possible.

## Overall Impression

Competent, honest, flat. Engineering integrity shows in the UI (degraded coverage disclosed, unlocatable spans admitted). But it reads as a data viewer for a scoring API, not a security tool. Biggest opportunity: make the verdict the loudest thing on screen.

## Cognitive Load: 6 of 8 failed — HIGH (critical)

Fail: single focus (History leads with poll panel), chunking (5-peer controls row), visual hierarchy (h2 < body; six identical panels), minimal choices (5 controls), working memory (bands + weight scale), progressive disclosure (six panels at once). Pass: grouping, one-thing-at-a-time.

## Emotional Journey

Peak should be the verdict; it's muted to a neutral number. Valley is a silent multi-second wait with no indication which layer runs. End is worst: the final panel asks the user for labor ("Was this right?") and a phishing verdict offers no recommended action — no report, delete, or don't-click.

## Minor Observations

VerdictDetail has no h1 (starts at h2 after a subtitle-styled back link). Two competing label treatments (14px h2 vs uppercase 11px th); the incumbent uses uppercase, so this diverges. RiskBadge falls back to the user-facing string "unknown" with no TONE key, rendering unstyled. .bar width is min(contribution,100)% of a 32%-wide cell, so lengths aren't comparable to a labeled axis. 14 em-dashes exceeds the advisory threshold.
